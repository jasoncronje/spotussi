Privacy

Updated November 23, 2026

The spotussi iPhone app collects nothing. It talks only to the spotussi server you run, and your listening history stays on that server. We never receive it.

Who runs what

spotussi is self-hosted software. You (or someone you trust) run the server on your own machine, and it keeps your Spotify listening history in one file there. The developer of spotussi does not operate a server for you, has no account system, and cannot see your data.

The iPhone app

  • No analytics, no tracking, no ads. The app contains no third-party SDKs and sends nothing to the developer or anyone else.
  • Your server only. When paired, the app sends requests to the server address you gave it, carrying a read-only API token. The token is stored in the iPhone's Keychain.
  • Artwork. Cover art comes from the addresses your server gives, which may be Spotify's image servers. Those servers see an ordinary image request from your phone; the app never sends them your token.
  • Camera. Used only while you scan the pairing QR code. Nothing is recorded or stored.
  • Local network. Used only to reach a server on your home network or VPN.
  • On the phone. The app keeps its last answers from your server in its cache so it can show them offline. Unpairing deletes the token and the cache. Deleting the app removes everything.
  • Demo. Try the demo shows bundled, made-up sample data and makes no network requests.
  • Open in Spotify. This hands the item to the Spotify app or website, where Spotify's own privacy policy applies.

The server

The server stores what you connect it to: your Spotify account's playback (through Spotify's Web API) and any streaming history export you import. It looks up artist and album details from Spotify and public music databases (Deezer, MusicBrainz, ListenBrainz) sending only the names it looks up, never your history. Whoever runs the server controls that data and can back it up, export it or delete it at any time.

This website

spotussi.app is a static page with no analytics or cookies. Its fonts load from Google Fonts.

Children

spotussi is not directed at children and collects no personal information from anyone.
