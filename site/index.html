From Stream to Dashboard

Follow three tracks from the phone they played on to your dashboard and your assistant.

  1. 1 · Stream

    Stream on Spotify

    Listen in Spotify on your phone, laptop or speaker. spotussi reads your player from your server every 12 seconds, so there is nothing to install where you listen.

  2. 2 · Ingest

    Each Stream Is Ingested

    Every read brings in the track, your position, the device and the playlist. When the track changes, spotussi stores one play with the seconds you listened and whether you skipped. Your history export lands in the same table, matched so nothing counts twice.

  3. 3 · Dashboard

    All Your Data, One Dashboard

    Overview, top lists and charts include the new play straight away, from today back to the first year you imported. A skip adds to your time listened and never to your plays.

  4. 4 · Ask

    Ask Your Assistant

    The built-in MCP server lets an assistant answer from your own history, with the same numbers as the dashboard. Scripts get them from the API.

FAQ

Premium

Yes. Spotify only lets Premium accounts create the developer app spotussi connects through. Every instance uses its own app, and the wizard walks you through making it.

Privacy

Into one SQLite file on your server. spotussi asks Spotify for read-only access only, and the free public catalog sources it uses for artwork and genres can each be switched off.

History

Request the Extended Streaming History on Spotify's privacy page and import the zip when it arrives. Raw rows are kept forever, so a rule change applies to all of it.

Artwork

Spotify allows apps like this about 150 catalog lookups a day. Public sources fill the gaps meanwhile, so a lifetime export has its artwork, durations and genres in about six to seven hours.

Assistants

Yes. The built-in MCP server answers assistants that hold an API token, using the same documented API the dashboard runs on.

Cost

There is nothing to buy and no subscription. It runs on any amd64 or arm64 machine with Docker, or as a static binary on Linux and macOS, and you can back it up while it runs with one command.
