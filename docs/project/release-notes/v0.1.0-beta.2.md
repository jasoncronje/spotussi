# spotussi v0.1.0-beta.2

The first release from the public repository. spotussi's source is now open under [AGPL-3.0-only](https://github.com/jasoncronje/spotussi/blob/main/LICENSE), and this beta is otherwise a small update to [v0.1.0-beta.1](https://github.com/jasoncronje/spotussi/blob/main/docs/project/release-notes/v0.1.0-beta.1.md), whose notes still describe what's in it and its known limits.

## Install or update

- **Docker:** `ghcr.io/jasoncronje/spotussi:0.1.0-beta.2` (linux/amd64, linux/arm64). `:beta` follows the newest beta.
- **Binaries:** static builds for Linux and macOS (amd64, arm64) below, with `SHA256SUMS`.

Back up before updating (`spotussi backup`, or Settings → System). No migration in this release.

## Changes

- **Catalog lookups: every track before any artist.** Spotify's daily lookup quota now goes to tracks, albums and playing contexts first, and artist lookups come last. A track lookup gives what the fallback sources can't (real artist IDs and credits, the canonical album); artist images and genres already come from oEmbed, Deezer and MusicBrainz in the meantime. On a lifetime export this fills the top 1,000 tracks in about 2 days instead of 4.
- **Verifiable builds.** Images and archives now carry GitHub build provenance attestations; check them with `gh attestation verify` as shown in [SECURITY.md](https://github.com/jasoncronje/spotussi/blob/main/SECURITY.md).
