# Project records

How spotussi is planned and built. User documentation is one level up, in [docs/](../README.md).

- [decisions.md](decisions.md): the decision record (D1, D2, …, deferred DF1, …), with the reasons and what was rejected
- [plan.md](plan.md): architecture, performance budgets and the milestone plan
- [release-notes/](release-notes/): one file per tag, used as the GitHub Release text by `release.yml`
- [screenshots/](screenshots/): screenshots and measurements from each milestone's review
